## Voltline Studios

## A Modern Gaming Studio Website | Five-Page Creative Experience

Voltline Studios is a modern, interactive gaming studio website designed to showcase games, communicate the studio's identity, connect with the gaming community, and provide an easy way for visitors to get in touch.

The website combines modern UI design, smooth animations, and engaging visual elements to create an immersive browsing experience.

Pages

- Home – Studio introduction and featured content.
- Games – Showcase of gaming projects.
- About – Information about the studio, its vision, and mission.
- Community – A dedicated space for gaming enthusiasts.
- Contact – Contact form for visitor inquiries.

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- React 18
- Tailwind CSS
- GSAP & ScrollTrigger
- Framer Motion
- Lenis Smooth Scrolling
- Canvas API
- Web Audio API

Getting Started

## Option 1: Open Directly

Open "index.html" in your browser. An internet connection is required for external scripts, libraries, and fonts.

Option 2: Run with a Local Server

python3 -m http.server 8000

Then visit:

http://localhost:8000

Customization

You can customize the website using these files:

- "js/app.js" – Update game content, text, and page information.
- "css/styles.css" – Customize colors, layouts, and animation styles.
- "assets/img/" – Replace or add website images.
- "assets/video/" – Add or replace background videos.

## Deployment

The project can be deployed to:

- Netlify
- Vercel
- GitHub Pages
- Any static web hosting provider

No build step is required. Upload the complete project folder to your hosting provider.

## Forms & Functionality

The Contact and Early Access forms currently display success messages on submission.

For real email delivery and form submissions, integrate a service such as Formspree or Netlify Forms.
