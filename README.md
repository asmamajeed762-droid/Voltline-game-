# Voltline Studios website

Five pages: Home, Games, About, Community, Contact.

## Run it
Open `index.html` in a browser (internet needed for the script libraries and fonts).
Local server: `python3 -m http.server 8000`, then open http://localhost:8000

## Publish it
Upload this whole folder to Netlify, Vercel, GitHub Pages or any web host. No build step.

## Stack
HTML5, CSS3, JavaScript (ES6+), React 18, Tailwind CSS, GSAP + ScrollTrigger, Framer Motion, Lenis, Canvas API, Web Audio API.

## Edit
- Games, copy, pages: `js/app.js`
- Colours and animation styles: `css/styles.css`
- Pictures: `assets/img`
- Background videos: `assets/video`

## Note
The Contact form and the early-access form only show a success message. To receive real emails, connect them to a service such as Formspree or Netlify Forms.
